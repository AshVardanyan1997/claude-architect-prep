# Day 4: Tools & MCP (18%) + Claude Code configuration (20%)

**Why today:** these were your weakest domains on the mock (7/11 and 9/12), and they hadn't had their own day yet.

**Goal:** for any configuration question, you can say *who gets it* (you or the team), *when it loads* (always, for some paths, or on demand) and *which layer owns it* (tool description, tool list, error shape, or prompt).

## Order of work (~2.5 h)

1. **Lesson (35 min):** [lesson/01-tools-mcp-claude-code.md](lesson/01-tools-mcp-claude-code.md). Start with the map in section 0.
2. **Tool drill (15 min, blank page):** [homework/01-tool-description-drill.md](homework/01-tool-description-drill.md).
3. **Build (75 min):** [homework/02-build-team-config.md](homework/02-build-team-config.md). This is the official Exercise 2: fix a team repo's CLAUDE.md, rules, skill, `.mcp.json` and MCP server (free, checked by `verify.py`), then watch it work in Claude Code.
4. **Quiz (30 min):** [homework/03-quiz.md](homework/03-quiz.md). 15 questions, 3 of them multiple-response.
5. **Check:** [answers/quiz-answers.md](answers/quiz-answers.md) and [answers/tool-drill-answers.md](answers/tool-drill-answers.md), then log your misses in [../error-log.md](../error-log.md).

Short on time? Do the lesson, the quiz, and parts A–C of the build. Part D (live Claude Code) is the part to drop.
