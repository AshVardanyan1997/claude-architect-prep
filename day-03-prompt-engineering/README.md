# Day 3: Prompt engineering and structured output, part 1 (20%)

**Goal:** for any prompt question, you can say whether the fix is *criteria*, *examples*, *schema* or *code*, and write the prompt yourself from a blank page.

## Order of work (~3 h)

1. **Lesson (40 min):** [lesson/01-prompt-engineering-part-1.md](lesson/01-prompt-engineering-part-1.md). It covers tasks 4.1–4.3 and where an extraction system runs.
2. **Prompt drill (25 min, blank page):** [homework/01-prompt-drill.md](homework/01-prompt-drill.md). Rewrite five bad prompts from five exam scenarios.
3. **Build (75 min, live API):** [homework/02-build-extractor.md](homework/02-build-extractor.md). An invoice extractor using a tool schema (the official Exercise 3, part 1). Your code goes in `homework/extractor/`.
4. **Quiz (30 min):** [homework/03-quiz.md](homework/03-quiz.md). 15 questions, 3 of them multiple-response.
5. **Check:** [answers/quiz-answers.md](answers/quiz-answers.md) and [answers/prompt-drill-answers.md](answers/prompt-drill-answers.md), then add your misses to [../error-log.md](../error-log.md).

**From your Day 2 review:** when you fix a prompt, delete the line you're replacing. The build's exercise 2 asks you to start from an empty file for exactly that reason.
