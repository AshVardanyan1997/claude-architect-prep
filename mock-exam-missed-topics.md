## Patterns across the 11 misses (for Day 4/5 targeting)

1. **System prompt wording steers tool choice (Q24, Q56, plus Q12).** Twice Ashot fixed the tool descriptions when the cause was keyword overlap in the system prompt (2.1 "keyword-sensitive instructions can create unintended tool associations"). Drill: given a prompt plus tools that misroute, find the sentence that causes it.
2. **Few-shot = teaching judgment, not coverage (Q40, Q46).** Picked prose or a dictionary over 2-4 examples with reasoning. Drill: write 2-4 reasoning examples for an ambiguous case and test them on unseen inputs (4.2).
3. **Heavy enforcement for a specification problem (Q12 forced tool_choice, Q51 hook, Q20 tool error).** Ask "what caused this?" before "what blocks this?". Hooks are for must-never rules; vague instructions get made specific (CLAUDE.md 3.6, descriptions 2.1).
4. **Misreading the ask (Q20, Q24).** "What is wrong with the agent" / "root cause" means eliminate options that change a different component or only describe a remedy.
5. **Built-in tool selection (Q05).** Grep content, Glob paths, Edit targeted, Read+Write fallback; Bash last (2.5).
6. **Delegation sizing (Q27, recurring with Day 2 Q4).** Delegate what would flood the coordinator context; do small scoped work directly (1.2, 1.6).
7. **Outside the official guide, low priority (Q21, Q26):** git worktrees, merge-then-rebase. Only keep: fork_session splits context, not files (1.7).
